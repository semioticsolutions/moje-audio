# Moje Audio v3 — odtwarzacz na górze

Zmiana względem v2: panel odtwarzacza znajduje się zaraz pod nagłówkiem, nad katalogami i biblioteką nagrań. Logika odtwarzania i schemat IndexedDB nie zostały zmienione.

## Aktualizacja na GitHub Pages
1. Wgraj pliki z tego archiwum do katalogu głównego repozytorium `moje-audio`, nadpisując pliki o tych samych nazwach. **Nie wgrywaj ZIP jako pojedynczego pliku.**
2. Potwierdź `Commit changes`.
3. W `Actions` upewnij się, że najnowszy `pages build and deployment` zakończył się zielonym znacznikiem. Jeśli publikacja się nie udała, poprzednia wersja pozostanie widoczna.
4. Otwórz stronę w Safari, a następnie ponownie uruchom PWA. Nowa wersja ma napis `Moje Audio v3` na dole strony.

Nie usuwaj ikony PWA ani danych witryny — mogłoby to usunąć lokalne nagrania. Zachowaj też kopie oryginałów.
